The split, on a half-hour where the array is actually producing. Same household, 2026-01-15 12:30 NZ, a 5.0 kWp roof: pv_half_hour puts 1.3592 kWh on the array for that slot. Against an own load of 0.7091 kWh, UN = max(0, 0.7091 − 1.3592) = 0 and EX = max(0, 1.3592 − 0.7091) = 0.6501 — two rows for the one instant. The generation figure is the real curve; the load is the same illustrative 0.7091.

Three things that never happen. A missing raw reading stays missing — a None slot is skipped, not interpolated, so a genuine LCL gap is still a gap in NZ. The wall clock never moves by hours, only by whole days. And a household's own load decides no membership question: not who gets panels (a hash), not who gets a planted load — except through planted.screen(), which can only ever leave a household out.
